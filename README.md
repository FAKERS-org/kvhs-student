# kvhs-student
Kravanh Hun Sen High School screen for Students

## Tech Stack
- [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Noto Sans Khmer](https://www.npmjs.com/package/@fontsource/noto-sans-khmer) for Khmer script support

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Features
- Student profile card (name, ID, grade, section)
- School information panel
- Score summary (total, average, letter grade)
- Per-subject score bars with letter grades
